Widgets

Blocks give form to content an author writes. Widgets are the application parts of a site — forms, search, calculators — that an author adds by pasting a single link, with no content to author at all.

Each widget below is running for real on this page, not pictured. Every one documents its parameters and can be downloaded as source.

To use one, put a link on its own line in a document:

https://main--eds-widgets--parkpx1.aem.page/widgets/cost-estimator/cost-estimator.html

Parameters go on the query string and arrive as data- attributes.
